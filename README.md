# Festivite

Formulário para criação de convites digitais, desenvolvido como projeto de
estudo para o curso de **Desenvolvimento Full Stack da Rocketseat**.

O objetivo deste projeto foi praticar HTML semântico, CSS, responsividade,
estilização de formulários, estados de interação e validação nativa do
navegador.

## Como visualizar

1. Baixe ou clone este projeto.
2. Abra o arquivo `index.html` no navegador.

Também é possível abrir a pasta no VS Code e utilizar uma extensão de servidor
local, como o Live Server.

## Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid e Flexbox
- Formulários e validação nativa do HTML
- Google Fonts
- SVG

## Observação

Este é um projeto de estudo focado na interface do formulário. O checklist
não exige backend, armazenamento de dados nem uma prévia dinâmica do convite.
Por isso, essas funcionalidades não fazem parte da avaliação atual.

## Aprendizados

Este projeto foi uma oportunidade para transformar uma referência visual em uma
página responsiva, organizar o CSS em arquivos separados e praticar recursos
nativos de formulários, acessibilidade e validação no HTML.
